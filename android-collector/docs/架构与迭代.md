# 架构与迭代约定

## 模块边界

```text
app：原生界面、操作队列、依赖装配、生命周期
 ├─ core：纯Kotlin领域模型、校验、采集状态机、仓储接口
 ├─ data → core：SQLite持久化、索引、事务、快照查询
 ├─ scanner：ScannerPort、优博讯广播适配器
 └─ export → core：SAF目录写入、版本化JSON、CSV、PNG、哈希
```

core不依赖Android、界面或数据库实现，所有箱瓶关系变化经CollectionWorkflow。不同品牌只实现ScannerPort。将来接入服务器，新同步模块消费版本化快照及任务UUID，不将网络调用塞入扫码回调，也不把线上状态覆盖离线原文。

首版使用系统原生界面和SQLiteOpenHelper以保持安装包小、离线运行及硬件依赖少。CollectionController和应用单线程队列负责串行处理，Activity仅提交命令与显示结果。模块数量按职责划分，不按每个页面拆包。后续页面增加时可独立提取展示组件，核心业务不迁移到控件。

## 数据与状态

- CollectionTask：独立采集任务UUID，固定码模式、内部码网址、装箱开关；生产批号是用户填写的真实资料，不能用任务号替代。
- BoxGroup：任务内组UUID与序号，boxRaw可空；先产品后箱通过同一组逐步补齐关系。组完成后不能追加/更正，必须显式重新打开。
- CollectedCode：产品码始终TEXT，持久化采集时间、来源与组关联。内部模式只保存32位；外部和箱码保存原文。
- AuditEvent：动作留档，记录删除码、原/新箱码、移箱前后组。任务资料修改与保存独立于扫码值。
- 扫码目标BOX/PRODUCT与当前组写入数据库，进程关闭后不依赖内存恢复。
- 数据库唯一键(task_id,value)及(task_id,box_raw)兜底本地任务去重；外键保障父记录存在。upsert先更新后插入，禁止REPLACE删除父记录。
- 每次操作在一个SQLite事务中提交码、组状态及审计，失败全部回滚。只在成功提交后向用户反馈“已保存”。
- 按任务及组建索引。每次扫码用索引查重、首码对照与计数，不重复加载全量码。记录按80条分页；导出一次读取一致性快照。
- 导出任务由应用级队列与状态管理，Activity旋转或切后台不会让同一导出重复执行，也不会提前恢复扫码。进程被系统终止后仅保留未完成目录，数据库码仍可重新导出。

## 扩展入口

| 新需求 | 修改位置与约束 |
|---|---|
| 另一品牌扫码器 | scanner中新增ScannerPort实现；core不变 |
| 产品/产线字典与文件导入 | data新增独立字典仓储，app提供选择器；资料选择不改扫码原文 |
| 托盘/多级包装 | 新增明确父子层级模型与迁移；禁止把箱码字段兼作托盘码 |
| 平台上传 | 新增sync模块，任务UUID及记录ID作为幂等键；先定义平台API及箱关系支持 |
| 服务器全局去重 | 上线校验补充本地判重，离线采集状态保留冲突详情 |
| 文件恢复 | 解析schemaVersion，验证哈希和关系后在单个事务内导入；不将JSON直接写库 |
| 更多任务字段 | 同步改模型、迁移、界面、导出schema版本与兼容测试 |
| 自动生产线设备接入 | 新ScanSource及专用队列，明确归箱事件；不根据扫描时间猜箱关系 |

## 发布契约

1. applicationId固定`cn.nz315.collector`，签名固定，versionCode严格递增。生产签名不提交、不打印密码。
2. 当前数据库v1。未来任何版本必须实现明确onUpgrade路径，并对旧库升级前后码值/箱关系/审计执行比对。默认拒绝未知迁移，禁止drop-and-recreate。
3. 导出schemaVersion与数据库版本分别维护。改变含义或结构时升schemaVersion，保留旧解析兼容说明。
4. 核心单元测试、本地数据库故障回滚、导出哈希与QR反解、扫码接入测试必须通过。同一个Android测试设备上的instrumentation串行执行。
5. 模拟广播通过不能替代i6310 PRO实体扫码头验收；每种固件和输出配置都先做原文对照，再试真实包装连续采集。

## 1.1.0联网生产边界

ProductionActivity与ProductionApi在app层独立接入服务器生产任务，使用原生HttpURLConnection和内存会话；不改变core/data/export离线模型与迁移。联网用码数据及管理员确认只在服务器持久化，服务器以task_code唯一占用及事务为事实源。客户端提交超时保持待确认并重试同码，不离线计已用。仅调试变体允许明文HTTP，正式变体要求HTTPS。新增6项网络协议JVM测试，build.ps1包含app单测。
