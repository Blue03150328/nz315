# 农资315 · 农药追溯码管理平台（SaaS）

依据 **《中华人民共和国农业农村部公告 第1049号》**（2026-11-01 施行）开发的农药标签二维码追溯管理平台，面向农药生产企业提供追溯码全生命周期管理。

> 📌 **AI 协作提示**：接手本项目的 AI 请按序阅读：[AGENTS.md](AGENTS.md)（用户全局偏好 + 项目记忆，最高优先级）→ [PROJECT_LOG.md](PROJECT_LOG.md)（变更档案）→ 本文件 → [PRD](农药追溯码管理平台%20PRD%20纯净版.md)（需求原文）→ [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)（部署）。

## ✨ 功能总览

### 消费者 H5（扫码即达，SSR 秒开）
- 扫码 URL：`https://{域名}/trace?code={32位追溯码}`
- 按 1049 公告展示：产品基本信息（名称/登记证持有人/剂型/毒性/规格/净含量）· 原药（母药）信息 · 批次信息（批号/生产日期/有效期至）· 质检信息（结果/合格证号/报告号）· 查询记录（首次/第 N 次 + 最近 5 次地域）
- 两状态差异化展示：已绑定（完整信息）/ 已生成（提示"尚未绑定生产信息"）
- 异常优先展示：已作废（不展示产品批次）/ 已冻结 / 登记证过期 / 产品过有效期 / 重复查询提示

### 企业管理后台（厂家 / 码管理员 / 总部管理员）
| 模块 | 说明 |
|---|---|
| 数据概览 | 累计/今日码量、扫码量、异常统计、状态分布、产品分布、扫码趋势 |
| 追溯码生成 | 1049 强制结构（1-11位）+ 自定义段（时间戳/校验位），重码检测，导出 TXT/CSV |
| 码库管理 | 列表/筛选/搜索，两状态（已生成→已绑定），异常标记（冻结/作废/恢复，作废终态），批量修正工具 |
| 产品规格管理 | 规格主数据（规格码=码第9-11位）、唯一性校验、引用保护 |
| 产品管理 | 产品 SKU（登记证全局唯一）；新增/编辑从**农药登记数据源**（97,471 条）选择登记产品自动回填登记信息（8 字段只读 + 原药按有效成分匹配三态联动） |
| 生产批次 | 批次三要素（生产日期/批号/合格证号）→ 码自动"已绑定"；有效期自动计算 |
| 生产采集 | 码文件上传 → 7 项校验（32位/类别/生产类型/规格码/登记证匹配/查重）→ 入库/绑定批次 |
| 扫码统计 | 总量/趋势/产品/地区/时段分布 + 明细 |
| 风险预警 | 8 类异常后台预警，扫码自动触发（重复查询/登记证过期已接入），核实合规/确认违规+一键作废 |
| 消息中心 | 预警/导入完成自动站内信，未读角标，跳转链接 |
| 系统设置 | 企业信息、用户权限（4 角色）、操作日志（保留3年）、数据备份（mysqldump） |

## 🛠️ 技术栈

- 前端/后端：**Nuxt 4.5**（Vue 3 + Nitro SSR）+ **Nuxt UI v4**（Tailwind v4）
- 数据库：**MySQL 8.0**（13 张表，`nz315`，含 pesticide_reg 农药登记数据源字典表）
- 认证：bcrypt 密码哈希 + HMAC 签名会话（7 天）
- 部署：单机 Node 服务 + MySQL，可前置 nginx（HTTPS）

## 🚀 快速开始（本机开发）

```bash
# 1. 安装依赖（npm wrapper 损坏时直调 npm-cli.js）
npm install

# 2. 配置数据库连接（.env，从 .env.example 复制填写）
cp .env.example .env

# 3. 初始化数据库（建库建表 + 演示数据，幂等）
node scripts/db-init.mjs

# 3.5 导入农药登记数据源（产品弹窗自动回填用；数据源文件不入库，见 .gitignore）
#     「2026农药登记证大全2.xlsx」放项目根目录后执行（本库已导入 97,471 条）
node scripts/import-regdata.mjs

# 4. 启动开发服务器（端口 3100，勿用 3000——被残留实例占用）
npm run dev -- --host 0.0.0.0 --port 3100
```

浏览器访问 http://127.0.0.1:3100

**演示账号**：`admin/admin123`（总部）· `lvfeng/admin123`（厂家主账号）· `codeop/admin123`（码管理员）

**演示追溯码**（已 seed）：`12301011001000000000000000001001`（正品·已绑定）、`12301011001000000000000000001002`（已生成）、`...0004`（已冻结）、`...0005`（已作废）

## ⚠️ 上线注意事项

- **合规硬节点：2026-11-01**（1049 号公告执行日），原 2579 号公告废止
