## 卡点速查

| 报错 | 原因 / 处理 |
|---|---|
| `应用目录不存在或为符号链接` | 现役不是 `/var/www/nz315`（或是个软链）→ 停手反馈 |
| `现役 PM2 路径不符合本执行单` | pm2 里 `nz315` 的 cwd / exec_path / 解释器 / 端口跟预期不符 |
| `当前 PATH 无 mysqldump` | 漏了 `export PATH="/www/server/mysql80/bin:$PATH"` |
| `备份程序必须为 MySQL8.0 mysqldump` | 该路径下的 mysqldump 不是 8.0 |
| `服务器缺少离线工具` / `现役离线工具校验不符` | `public/tools/nz315-qr-tool-v1.2.0.exe` 缺失或不是官方 v1.2.0（SHA256 应为 `04373ae1dc21752636f1b68945edb2dca8cff19c8b005b2ace1070cbc0a72fe8`） |
| `存在本执行单未覆盖的缺表或缺列` | 线上库结构与源码不符 → 停在准备阶段，**不会动数据** |
| `已存在本次候选或备份目录` | 之前已跑过 `prepare` → 先看原结果，**别重复执行** |
| `准备后线上版本已变化` | 准备到发布之间公网指纹变了（有人在部署）→ 停手核对 |
| `其他 PM2 进程状态发生变化` | 期间有人动过 PM2 → 按事实核对，脚本保守中止 |
