# 农资315生产扫码 Android 3.1.11

当前版本统一从“生产扫码”选择生产线、产品和生产资料；支持内部、外部码识别、离线保存与自动同步。“我的记录与备份”可离线搜索本机当前账号全部历史，支持产品、商标、批号、生产线、日期和记录编号，多个关键词用空格组合；每次显示30条，可继续加载。搜索不访问服务器，导出和完整备份保留。

“历史记录与旧队列”仅用于早期版本的本机数据和补传队列。入口直接显示旧数据概况、完整备份，不会要求重新激活设备；确有未完成旧队列时才显示恢复入口，补传仍使用原认证。当前账号的日常记录在“我的记录与备份”。

包名 `cn.nz315.production.pda`，versionCode 20，线上版 `3.1.11-online`，默认接口 `https://www.nz315.cn`。支持 Android12 UROVO i6310 Pro / CT58 广播与键盘扫码。覆盖更新沿用原签名，不卸载清数据；每次安装先做备份。

## 日常流程

1. 管理员登记设备所属厂家，生成5分钟有效的激活二维码；设备不固定绑定员工或生产线。
2. 工人激活设备，用自己的生产操作员工号登录。首次使用须联网，授权和产品资料加密／持久缓存，不保存明文密码。
3. 点击生产扫码，从下拉列表选择本厂生产线，选择本厂启用产品。产品显示商标、成分含量、剂型、规格和登记证号，不要求产品已有入库码。
4. 生产日期默认当天，有效期默认两年后，批号手填，日期可修改。
5. 确认资料时联网登记当前任务及会话，服务器自动匹配或创建该线当前任务。首次登记确认前不收码；登记后可离线继续。
6. 点击开始连续采集，每件先写本机SQLite事务，再提示保存。按唯一完整32位码判断，保留前导零，域名和网址完整性不影响同码判断。
7. 暂停／返回停止收码；每10～15分钟随机上传，每批最多20条，事件UUID和序号固定，收到逐条收据才减少待上传。
8. 结束采集提供5秒取消窗口，确认后冻结原批，自动上传。离线显示导出TXT或联网补传；全部参与设备的事件、结束标记及封存收齐后，后台自动结束任务。

有效生产采集上传才创建或绑定码库记录，生成码本身不等于生产入库。重复、缺位、错误产品等异常保留原文和原因，不新增有效码。原批的工人、设备、产品、批号与日期保留，不能覆盖其他已生产码。

## 重开与离线

工人登录状态不跨应用进程自动恢复。重开后验证自己的工号，再继续原批；已缓存账号可在72小时授权内离线登录，原记录及上传计划保留。

在线重新登录会更新工人授权。继续原批时只封存旧授权会话并追加新会话，旧事件沿用原身份补传；自动归线的新会话先联网登记。授权未变的已登记会话可离线继续。不会因重新登录重建生产批次或修改已采集资料。

授权过期、停用或明显时间回退时停止新采集，原记录保留。设备被删除后联网核验转激活页，未确认的旧记录仍保护。覆盖更新使用原签名，不卸载正式应用或清除数据。

## 外码和备份

外码模式独立保存完整二维码原文，不把域名替换或只导出code，也不触发内部生产绑定。TXT导出本人的去重原文，名称标注外码采集、公司、工号、设备及数量／时间。本人完整JSON备份保留原文、归属和上传收据，不含密码或设备凭证。

生产TXT为带签名的结构化记录，名称包含公司、日期、产品、批号、生产线、工号、时间和记录号，可用于后台生产记录导入；普通一行一个码的TXT不能替代完整追责文件。本机产品资料及记录存在应用私有SQLite，不是产品文本文件。

## 构建和实机验收

JDK17、SDK35／build-tools35.0.0，沿用原APK签名：

```powershell
.\build.ps1 -JavaHome 'C:\path\to\jdk-17' -AndroidSdk 'C:\path\to\Android\Sdk' -Online
```

输出 `app/build/outputs/apk/online/app-online.apk`。独立测试包名 `cn.nz315.production.pda.workertest`，通过 `-PpdaTestServer=http://127.0.0.1:38125` 配置隔离后端，使用ADB反向端口连接。不得把隔离脚本指向正式数据库。
