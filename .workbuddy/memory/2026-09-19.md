## 前端按角色收口 + 补齐三项后端遗留（当日完成）

- **① 会话吊销**：`user.session_epoch BIGINT` 新增列（`db-init.mjs` DDL + 幂等 migrate 双写，已实跑）；token 由两段 `userId.expiry` 升为**三段 `userId.expiry.issuedAt`**；`getCurrentUser` 加 `issuedAt < session_epoch → null`（**严格小于**，防同毫秒「登出即重登」误杀）；`logout.post.ts` 与 `reset-password.post.ts` 刷 epoch。**旧两段 token 主动拒绝** → 部署后全员需重登（预期）。
