## 数据口径约定

- **库里的演示/测试数据仅供功能验证，数值本身不可信**（用户 2026-09-12 明确："这部分数据只供测试用，数据填写可能不准确"）。

  - 涉及"数据是否合规"的判断，必须在真实业务数据上做，测试库得出的只能叫"可能性"，不能说成结论。
