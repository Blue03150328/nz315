## 二、仍有效的硬知识

- **外码构造公式**（可零写入触发「登记证过期」等分支）：`类别位(1=PD/PDN/LS/EX，2=WP/WPN/WL) + 登记证后六位 + 生产类型位 + 21 个 0 + 3 位序号` = **32 位**。

  两套会话**不可互换**：后台 `nz315_user`（7 天三段式 + `session_epoch` 吊销）、消费者 `nz315_consumer`（30 天，`consumer:` 前缀）。
