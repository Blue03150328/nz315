# 安卓3.1.11：生产准备关键词搜索（本机候选）

生产准备中的产品和产线数量较多时，工人需要快速定位目标。本轮基于本机3.1.10候选接续，保留页面候选按钮、扫码反馈限高和底部操作栏修复，新增两处关键词搜索。

- 产线：点“选择产线”展开独立关键词输入框、匹配数量和候选列表。搜索不修改已填产线；点候选才回填。支持清空、空结果提示和原有直接手输，继续原批时保持锁定。
- 产品：在产品选择框上方输入名称、商标、登记证号、规格、含量或剂型，实时缩小候选并显示匹配数量。支持空格分隔多词、全角及大小写归一，清空恢复全部产品；未匹配的已选产品以“已选”标识保留。
- 使用本厂完整本机缓存筛选，无网络搜索请求，无分页截断；离线可查。筛选不会触发产品切换，不清空已填批号和日期。缓存更新保留关键词、仍存在的已选产品与已填资料；产品从新缓存移除时取消旧ID。实际产品切换继续走原有资料与续批校验。
