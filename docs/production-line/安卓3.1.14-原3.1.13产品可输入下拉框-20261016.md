# 安卓3.1.14：基于原3.1.13的产品输入下拉框

用户提供原3.1.13 APK，明确要求取消产线筛选，产品改成点击后直接输入、下方显示关键词匹配选项。

## 基线及修改范围

原包SHA256为d5771993f3e30e2501c5578be057b9af40672b01a8cd3d9b1c875c164637a6ed，与USB扫描仪此前保存的3.1.13完全相同。通过GitHub连接读取主仓175c4ff56328d7da69550fa865380b6e1c5921db，原APK内worker.js、worker.css、production-preparation.js与该版本逐字一致。

本机之前停留在3.1.11，现同步对应3.1.13的Android源码与测试，保留线长与普通工人权限、本厂及本机记录查询、原文导出、开始暂停动作及上传收齐协议。本轮未修改这些3.1.13原生业务实现；MainActivity、WorkerEngine、WorkerStore及原worker.js/CSS已与锁定基线逐字比对。没有移植网站源码、执行后端发布或写正式业务库。

产品增强放在独立product-picker.js/CSS，由工人页面加载。保留原产品select作为真实数字ID及change事件的载体，界面显示可输入的组合下拉框：点击展开全部产品，输入名称、商标、规格、登记证号等关键词即时缩小候选，点击才切换产品。支持全角及大小写归一、空格多词、方向键和回车选中、Esc收起。产线选择使用原3.1.13普通select，无产线搜索框。

输入未匹配产品时保留实际选择，下面显示“已选”，离开输入框回显产品；重新选择同一产品不重置批号和日期。新选其他产品继续调用原版切换与续批锁定逻辑。缓存刷新保留搜索词，失效ID由原版缓存逻辑清除。候选长文本换行、有界滚动，不新增弹窗或额外搜索栏。

触摸回归发现，pointerdown阶段立即收起列表会移动原本要点的资料栏，可能误点下方开工按钮。已改为click落到原目标后再收起，补充“选择产品、收起列表、回车不误点开工”的回归断言。
