# 生产管理与产线总览

侧栏“生产任务”调整为“生产管理”，入口 `/admin/production-tasks` 默认跳转独立生产线管理页面。顶部保留三个页面：生产线管理、生产任务、历史外部采集。

## 操作

1. 点击生产管理 → 生产线管理 → 添加生产线。总部管理员先选择厂家；厂家管理员只管理本厂。
2. 输入生产线名称，输入厂长姓名或从已登记负责人中选择。负责人是独立姓名标识，不创建登录账号、不赋予扫码权限，也不作为操作员安排。
3. 保存只创建产线档案，不预建任务。工人下次刷新缓存可选择该线；工人实际开工后服务器自动创建任务、登记操作员和设备。
4. 产线列表一行一条线，包含厂家、名称、负责人、运行状态、运行／暂停／离线／待同步设备、当前产品、进行中任务数、有效／重复／异常码数、最近上报。
5. 点击编辑可改负责人；尚未关联任何任务的产线也可改名。已有任务的名称保留，避免影响历史归属和未完成采集。负责人编辑不改变任何任务、工人、设备或生产资料。
6. 点击查看扫码情况，跳转生产任务并带入本条线及厂家筛选。任务列表中的人员称为操作员；员工详情继续显示实际姓名工号、设备、产品、批号、有效／重复／异常码、开始／停止时间和采集状态。

产线和任务均复用同一个 Excel 式网格组件：四边网格、单格单行、横向滚动、整列拖动／Alt加左右键、列宽调整、显示列选择、账号独立保存布局。生产线管理支持模糊查询及厂家／生产线／负责人／状态表头筛选。

## 统计与兼容

- 产线长期存在，任务是每轮生产。历史任务中的产线会出现在总览，编辑时补建档案，不需人工重建原任务。
- 仅有已删除任务、没有现有产线档案的名字允许重新登记；不会恢复旧任务或覆盖旧码资料。已有产线档案和可见历史产线仍防止重复创建。
- 每10秒刷新页面。设备仅统计本线未结束任务中的采集会话，并按设备ID去重；超过90秒没有有效心跳显示离线。沿用原有运行、暂停、离线、结束待同步判定，心跳不代替正式上传收据。
- 总览顶部汇总当前账号可见全部产线的设备，分页和查询不改变汇总。码数只计算未删除任务中的服务器确认记录；重复和异常分开计数，不采用手机本机数。
- 任务页面去掉设备数量列和顶部设备汇总，只关注实际扫码、操作员和起止时间。负责人不会进入任务操作员筛选。
- `/api/admin/production-lines` 原任务接口保持，新增 `/api/admin/production-line-management` GET／POST／PATCH 和 `/options`。管理员写权限、企业隔离及编辑日志由服务器执行。
- 自动归线、原任务结束闸、旧APP、历史外部采集接口及队列保留，本次不改APK。
