# 生产任务删除

总部管理员可删除所有厂家的任务；厂家管理员仅可删除本厂任务。码管理员、只读账号及生产操作员不能删除任务。

1. 打开「生产任务」，先确认工人已结束采集、记录已经上传或导入，并结束后台任务。
2. 删除单条任务：点击该行右侧垃圾桶按钮，核对任务名称与生产线，点击「确认删除」。
3. 批量删除：勾选任务左侧复选框，或使用表头复选框选择当前页可删除的任务，点击「批量删除」，核对清单后确认。
4. 进行中、旧流程尚未审核完成、存在未结束会话或上传序号缺口的任务不能删除。批量删除任一任务不符合条件时，所有所选任务保持原样。

删除从任务列表移除记录，保留追溯码、批号、日期、有效期、人员与设备扫码记录、上传收据及码占用。消费者查询与历史码明细继续可查，不释放码、不改变已生产资料。删除审计保存操作人、时间、原状态及批量清单；响应丢失重试不重复操作。

接口：

- `DELETE /api/admin/production-tasks/:id`：删除单条任务。
- `DELETE /api/admin/production-tasks`：请求体 `{"ids":[1,2]}`，最多100项，重复编号自动去重。
- 成功返回 `ok`、`deletedCount`、`deletedIds` 和 `alreadyDeletedIds`。401表示未登录，403表示无权限，404表示编号不存在或不属于本厂，409表示任务尚不符合删除条件。

复用既有任务状态与修改审计表，无数据库迁移，无安卓应用变更。隔离数据库7组删除验收和原生产线6组回归通过；75项单测通过、4项既有跳过；生产构建通过。类型检查保留已有诊断，本次新增代码未增加诊断。浏览器验证多选、取消、确认、数量更新和不同窗口宽度的行内操作布局。
