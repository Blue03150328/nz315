# 单次上传生产资料修正（2026-10-13）

码库管理的“修正生产信息”只影响当前这条上传记录的具体码。例如一条记录为6张，修正范围就是这6张，不修改同任务、同码文件或共享业务批次中的其他上传记录。

## 操作

1. 扫描仪结束本次采集并上传全部记录和结束标记。
2. 后台结束关联生产任务。
3. 码库管理找到对应上传记录，点击“修正生产信息”。
4. 核对弹窗实际码数，填写需要修改的批号、生产日期、有效期、质检结果或合格证号；留空表示保持原值。
5. 可填写修改备注，勾选确认后提交。页面提示本次修正的实际码数。

仅管理员或任务创建人可修正；冻结码需先恢复正常，包含作废码时不允许修正。列表禁用按钮提供具体原因。独立产品的新上传记录与历史流程都适用。

## 一致性与审计

接口以上传记录ID和其所属码文件共同限定范围，并校验预览版本。并发修改或码清单变化要求重新预览；相同请求标识重试只修改一次。所选码字段、该上传记录快照、来源文件汇总及审计日志在同一事务内完成，日志失败整体回滚。

日志记录操作人、时间、上传范围、逐组码ID、原始及有效旧值、修改值和备注。原始采集事件、收据、工人设备归属、共享batch和task生产资料保持不变。重新生成码库投影也不能覆盖已修正的上传快照。公众查询、单码详情和列表使用实际修正值。
