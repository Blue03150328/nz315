# 统一生产扫码与内外码库（2026-10-14）

## 来源规则与记录

- 本站主域名／裸域名或配置入口，严格比对域名、端口、路径和唯一32位码参数；完整32位裸码按内部产品码校验。本站坏链接不能绕过校验进入外码库。不会从任意文本中截取32位数字当作新版内部标签。
- 有效外站HTTP／HTTPS标签地址归外部来源，保留完整原文。无法识别、含凭据、片段、非法转义、本站错误路径／端口或错误码格式的内容记录异常，不建有效码。仅网址归属不能代表标签真实性。
- 内部码沿用产品完整11位头、占用和已有生产资料保护。外部原文由企业唯一键裁定跨设备、跨产品、跨轮重复，兼查历史工人原文；不把外码中的数字参数映射到内部码。
- 事件UUID、连续序号、原工人授权、原始文本与服务器收据共用原事务协议。入库或收据任一步失败整体回滚。生产TXT签名导入与设备补传同口径、重播幂等。
- 仅新版`unifiedScan`会话使用新规则；旧采集、旧APK与未确认队列保持原协议。历史记录不批量重新分类，不迁移、不回填、不删除。

## 页面与采集器

生产任务主表和员工设备详情分别显示内部码、外部码及有效码合计；设备心跳、运行状态及全部参与者完整结束后自动完工沿用。码明细可切换内外来源。

码库共用`/admin/codes`入口，通过内部码／外部码切换。内外主表和明细统一使用生产任务网格，支持横滚、拖动整列、调列宽、选择显示列和按账号保存／恢复布局；原筛选、多选、导出及权限保留。查询和分页不会丢失来源视图。旧外码路由跳转到新入口，原独立外部采集可从生产任务页的历史入口查询。

外码入库直接带本次产线、设备、工号、产品、规格快照、批号、生产日期及有效期，不需要再次补资料。历史无资料记录仍显示未记录，不虚构。
