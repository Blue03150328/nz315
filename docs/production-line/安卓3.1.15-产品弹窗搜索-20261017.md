# 安卓3.1.15：产品选择弹窗内搜索

用户要求点击选择产品后弹出窗口，在弹窗内搜索和选择，并通过 USB 更新扫描仪。

## 实现

基于本机已与原3.1.13对齐的3.1.14测试版，仅调整产品选择交互。页面显示产品选择按钮，点击打开原生 HTML dialog 模态弹窗，搜索框支持名称、商标、规格、登记证号及空格多词，沿用全角和大小写归一。显示匹配数、当前已选、清空和取消；产品长文本换行，候选独立滚动，弹窗随可见视口缩小，适配软键盘。

点击候选才切换真实数字产品ID，继续调用原select change与续批锁定逻辑。同产品重选不清空批号日期。取消、Esc、点击遮罩及Android返回只关闭弹窗，App退后台时关闭弹窗。保留原产线select、工人权限、记录与动作上传协议，未修改Java业务源码。
