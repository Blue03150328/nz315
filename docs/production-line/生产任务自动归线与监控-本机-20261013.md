# 生产任务自动归线与设备监控（本机候选，2026-10-13）

本轮只在现有“生产任务”模块修改，名称与菜单不变，不新增业务模块。用户明确要求先在本地保存回滚历史，暂不推送远程、不部署、不打包或安装APK。明天连接Android12设备后再构建及实机验收。

## 管理者与工人流程

管理者登记设备名称和所属企业，生成5分钟有效的一次性激活二维码；不配置固定生产线或员工。设备激活后，工人用自己的工号登录。

工人进入生产准备，输入生产线名称或者从已缓存的本厂生产线下拉选择。选择本厂启用产品，列表显示商标、产品名、成分含量、剂型、规格、登记证号；产品信息不要求先有入库码。日期默认当天，有效期默认两年后（闰日回退至月底），批号手填，日期均可修改。

确认资料后，APP先保存本机采集会话，再联网登记本轮生产线。服务器匹配该线当前进行中的不固定产品任务；没有任务时自动建新一轮，并按可信工人授权登记参与人员与设备。同线并发开工只建立一个任务。管理员预建任务是可选步骤，未预设人员也可以开工。已绑定码文件的旧任务与旧队列保持原范围，不自动并入新轮。

首次加入本轮需要联网登记；未拿到登记收据禁止收码，失败重试保留原会话UUID。登记后可以离线采集，每条扫码先提交SQLite，成功才提示保存。重复和异常保留原文。正在进行的原批资料固定，继续原批时不覆盖日期和批号。

采集期间上传周期仍为10～15分钟随机间隔；状态与本机统计使用独立30秒轻量心跳。暂停或返回即停收码；结束采集保留5秒可取消缓冲，确认结束后自动补传。恢复联网及时补传，断网保留队列、TXT和备份入口。

## 自动结束与监控口径

任务只展示进行中、已结束。后台取消手动结束按钮，接口也拒绝人工提前结束；已经结束任务的旧结束请求只返回幂等收据。

实际加入过任务的设备全部完成采集，全部采集序号与结束标记确认，所有run封存且上传批次完成后，服务器自动结束任务并留审计。一台设备结束不会结束其他设备所在任务；暂停、离线、关机不算结束。设备上报的序号如果大于已上传最终序号，也不能结束。

运行、暂停、离线／未知、待同步、已结束按唯一设备统计，避免同设备多次采集重复计数。90秒没有新鲜心跳视为离线／未知，保留未完成状态。按用户后续确认，后台只显示服务器已确认的有效码、重复码、异常码，移除APP本机数量与“云端”标签；心跳用于设备状态，不能代替上传收据，也不会创建或绑定码。

首次登记是自动结束的必要约束：完全离线、从未登记的设备不能直接开启本轮生产，否则云端无法知道它参与过。已经登记的设备断网采集不会导致任务提前结束。

## Excel式页面

生产任务列表显示任务、生产线、操作员工号、操作员姓名、产品、状态、各设备数量、有效／重复／异常数量和起止时间。每字段单列、数据单元格单行且四边网格清晰，支持横向滚动、拖动整列顺序、拖动列宽；拖动时整列高亮，表头、全部行内容及列宽同时移动。布局按当前后台账号保存在本机浏览器，提供恢复默认列与Alt加左右键移动列；单套统计采用v2布局缓存，保留旧布局供回滚。

模糊搜索支持任务、生产线、员工、设备、实际产品、商标、登记证号及批号；表头下拉支持生产线、操作员姓名、状态，另有操作员及时间筛选。自主选择的产品也能被搜索到。点击“员工详情”可查看每名工人的产品、有效码／重复码／异常码及起止时间，不显示APP本机计数。

“查看详情”一行对应一名工人的一次采集，工号、姓名、设备、产品、商标、含量、剂型、规格、证号、批号、日期、各数量、起止时间及同步状态独立列，继续查看该工人的原文、异常原因与采集／上传时间。详情同样可拖列、调宽、查询，每10秒刷新可见页面。

管理员可删除无意义的任务列表记录。未开工、没有任何注册会话或码记录的空任务也可删除；正在采集或未完整同步的任务不能删除。删除为软删除，已采集码、生产资料、身份及审计不删除、不释放。

## 兼容、结构与回滚

新增一张production_line_runtime协调表与worker_session的8个心跳字段。独立脚本为scripts/migrate-production-monitor.mjs，必须显式指定与.env一致的数据库名；本轮只在本机隔离测试库迁移并验证重跑，不迁移实际业务库。完整发布脚本也纳入此增量，未来上线时单独受控执行，不运行演示初始化。

旧APP的缓存保持stockVersion2；新工人端请求monitor=1获得stockVersion3与可复用产线候选。旧session/run的UUID、原工人、设备、队列、生产资料与收据保持不变，只有完整结束才自动结束关联任务。原单次上传6张修正范围与日志保持。

本轮安卓源码编译和Lint通过，SQLite/JVM测试覆盖开工未登记禁止收码、原会话重试、错误收据回滚、断电重启和持久心跳版本。网页类型、生产构建和单测通过；9组新自动任务、8组生产后入库、8组旧生产线、9组单次上传修正、5组外码真实隔离接口通过。浏览器验证列拖动／宽度保存、单行单列、设备员工详情及第二个产品准备参数；手机页面采用模拟Native桥接，不等同实机验收。
