## 4. 硬约定速查（改错会出生产事故）

### 4.1 部署
- **补列补索引一律 `node scripts/db-init.mjs --migrate-only`** —— **不可省**。裸跑会 `seed()` 演示企业 / 4 条演示码（进 `trace_code` 核心表）/ `admin123` 账号 = **生产数据污染**。
- 与 www.cynx.cn **共用 PM2 daemon**：**绝不 `pm2 kill` / `pm2 delete all`**，只 `pm2 reload nz315`。
- `nz315.conf` 绝不写 `listen 443 ssl default_server`；绝不传本机 `.output`。
- **改 `.env` 必须重新 build**（runtimeConfig 构建期内嵌）；顺序 = 补列 → 构建 → reload。
- 工具包（`public/tools/*.exe`）必须在 **build 之前**放好（静态清单构建期固化，漏了会 404）。
- 上线交付 = `git archive` 打 tar 包 + SHA256 校验；**AI 不直连 SSH**，由用户在宝塔终端粘贴执行。
- 🔎 **「包是否过期」的判据**：`git archive` 在包首写 `pax_global_header`（内容 = `comment=<sha>`）⇒ **同内容、不同提交打出来的包 SHA256 必然不同** ⇒ **判过期必须逐文件比内容，绝不能比 SHA256**。
- 服务器上 `mysqldump` **必须加 `--no-tablespaces`**（库账号无 PROCESS 权限，默认会报 `Access denied ... tablespaces`，**非致命**但会被误判成失败）。**备份有效的判据是 `gzip -dc db.sql.gz | tail -3` 里有 `-- Dump completed on …`**。`ls -lh` 看不到 `.env`，备份验收用 **`ls -la`**。

### 4.2 数据库与代码
- `server/utils/db.ts` 的 `query()` 返回**行数组**；raw `mysql2` 的 `conn.query()` 返回 **`[rows, fields]`** ⇒ 混用必错，统一收口 `firstRow()`。
- DB 连接配了 **`dateStrings: true`**（`expire_date` 等 DATE 返回 `'2026-09-22'` 字符串，不是 Date 对象）—— 依赖日期字符串比较的逻辑都靠它成立。

### 4.3 git（本机特有）
- 工作副本在 **`ycdb`**（非 master），未合入未推送。
- 本机 git 两个老毛病：**① 写不了嵌套引用**（`refs/heads/a/b` 静默失败，全命令 exit 0 无报错）⇒ **本地分支名用平铺名**；**② `checkout` / `merge` 后只落地差异文件**、`git status` 报一堆 ` D` ⇒ **`git reset --hard HEAD` 即铺回**（文件没丢）。
- 判定「文件是否缺失」**只能用 `git status`**：`git ls-files` + `fs.existsSync` 会因 `core.quotePath` 把中文名转义成八进制而**假阳性报缺失**。**碰中文路径的 git 输出，一律加 `-c core.quotePath=false`。**

| 4 | **依赖分散在三处 `node_modules`** | `Cannot find module '@zxing/library'` | `@zxing/library` 在**项目** `node_modules`、`qrcode` 在**隔离工作区**、`pngjs` 挂在 `qrcode/node_modules` 下 ⇒ 临时脚本的 `load()` **必须多基路径兜底（三处都列）** |
| 5 | **`ui-shot.js` 点不到自定义可点击元素** | `ERR 未找到可点击目标（按可见文本精确匹配）：点此反馈` | 命中集合只有 `button/a/tab/菜单项/…` ⇒ 改用 `--js-file` 跑 IIFE 探针自己找元素 `.click()` |
| 6 | **`--js-file` 的内容是「表达式」不是脚本** | 顶层 `return` / 顶层 `await` 会 **SyntaxError 且被静默吞掉**（连 `JS>` 都不打印） | 包成 `(async () => { … })()`；且 `--click` **恒在** `--js` 之前执行 |

### 5.2 高频老坑（仍然有效）

- **同一文件的多次 Edit 绝不能并行发**（写覆盖竞态：两个都报成功，后写回的覆盖先写回的）。
- **`node --check` 只查语法、不查未声明引用**：`return { undefVar }` 语法合法、`--check` 静默通过，运行时才 `ReferenceError`。改了 Vue `setup()` 的 `return {}` 或 computed，**必须真浏览器验证**。
- **前端 Vue / SPA 修复必须真实浏览器验证**：DOM 完整 ≠ 视觉正常。
- **失败命令的 fallback 输出绝不能当证据**（`grep ... || echo "..."` 打印的"结论"是假话）。
- **「上限/截断/唯一性」类怀疑必须用真实数据算边界**，不能靠读代码定性（26 号曾因此误判 `LIMIT 20` 会丢候选）。
- **「已修」≠「已上线」**；判定"线上还有没有这条毛病"要**实测**。
- **报告数 ≠ 落库事实**：`/api/bill` 返 **401 不能证明表存在**（鉴权在查库之前）；`--apply` 报「待写入 0 条」**既不能证明写成功也不能证明没写**（只反映冷却期是否放行）。**要判落库必须回库里查。**
- 判定「目录可读」看 **`ls -la` 能否列出内容**，不是 `ls -ld` 的属性行（`ls -ld` 曾抽风打印 `d?????????`）。
- 本机 `npm run build` 走不通（沙箱缺 `/usr/bin/env bash`）⇒ 改 **`node node_modules/nuxt/bin/nuxt.mjs build`** 直接调 CLI。
