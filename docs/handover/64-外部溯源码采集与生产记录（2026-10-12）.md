# 外部溯源码采集与生产记录

日期：2026-10-12。状态：本机代码、页面和数据库已完成；未推送、未部署，未安装实机。

## 一、用户确认的流程

厂内已有外部二维码 → 主采集器扫描 → 完整原文保存后台 → 完成一次采集 → 后台补生产资料 → 按本次采集导出CSV或TXT → 交由标签厂家设置对应溯源内容。

- 保存二维码完整内容，包括网址前缀、路径、参数、大小写和前导零；不提取内部32位码，不访问来源网址。
- 同一厂家跨设备、跨采集批次重复原文提示且不新增；不同厂家可保存相同原文。比较按完整字符，不合并不同参数顺序、大小写或空格的内容。
- 扫描持续自动上传；断网本机保存，恢复后补传原采集批次。“完成本次采集”固定边界，下一次扫码创建下一批。
- 同一厂家生产批号允许多条采集记录，以设备登记生产流水线快照、本次工号及采集时间区分。
- 流水线取可信设备登记，工号现场填写。工号是业务字段，不等于个人登录身份；个人账号登录仍由用户同事接入。
- 每次采集对应一条外部生产记录。产品可选择本企业已有产品，也可手输名称；手输名称只保存该记录，不创建产品主数据。
- 生产批号是厂家的实际生产批号；日期是生产日期。资料在采集完成后由后台补填或修改。
- 实际采集码数按后台去重成功入库数统计，不可手改。生产数量默认跟随实码数，也可手填，两者分别保存。
- 例如实际入库10000条、生产数量手填9800，导出仍为10000条。导出范围始终是整次采集，不随当前搜索条件缩小。
- CSV仅一列“溯源码”，UTF-8带BOM，按标准转义双引号和逗号；TXT无表头，每行一个完整原文。文件不追加生产字段或改写码值。

## 二、操作方式

1. 管理员在“生产任务与审核 → 设备管理”登记设备及生产流水线，设备完成激活和一次联网归属核验。
2. 主采集器任务列表点击“外部二维码采集”，填写本次工号，开始扫码。若内部生产采集未结束，先上传并结束原采集。
3. 扫码先落本机SQLite事务，再反馈已保存；同步按20条分段自动执行。界面分别显示本机初步去重、云端入库、重复、未入库和待补传。
4. 点击“完成本次采集”。断网时先保存结束边界；补传全部事件并取得云端完成收据后，后台才显示采集完成。此后扫码形成新批次。
5. 后台“外部追溯码 → 外部生产记录”查看按次记录，补填产品、厂家生产批号、生产日期和生产数量。
6. 在记录详情导出CSV/TXT，或到“外部码库”选择已完成批次并导出。无需为了码文件导出而修改实际码数；完成批即使生产资料尚未补齐也可导出。
7. 将文件交给标签厂家。系统不自动联系标签厂家，也不向外部溯源网站写入内容。

本机入口：`http://localhost:3100/admin/external-production` 与 `http://localhost:3100/admin/external-codes`。

## 三、实现与数据关系

外部模块使用既有MySQL连接中的三张独立表，不混入内部`trace_code`、`batch`或生产任务绑定。外部码库业务内容只显示溯源码原文；关联ID、企业归属、摘要及接收时间用于权限、去重和可靠上传。

| 表 | 用途 |
| --- | --- |
| `external_collection_batch` | 一次采集及外部生产记录；厂家、设备/流水线快照、工号、状态、双数量、产品名称、生产批号、生产日期 |
| `external_trace_code` | 完整原文、企业范围摘要唯一索引、所属采集批次、事件序号和采集/收到时间 |
| `external_collection_event` | 固定事件标识与序号、内容摘要、终态收据；支持重试且不重复计数 |

- 原文以UTF-8计算SHA256，企业和摘要唯一；摘要碰撞再对比原文，不静默丢失不同内容。
- 每条事件独立事务，码、收据、序号和计数同时提交；批量中途失败只确认已提交部分。
- 同事件重放返回原收据；同序号内容被篡改、跨设备冒用、序号缺口或完成后新增均拒绝。
- 完成必须收齐固定最后序号。完成回包丢失后，同企业原设备合法调线仍可复核完成状态，历史产线不改。
- 原文最多8192个UTF-8字节；不允许码内CR/LF/NUL、空内容或不完整Unicode字符。单事件输入绝对上限64KiB，超过存储限制的可解析事件形成拒绝收据，不能入库。
- 扫描头附加的末尾回车/换行由已有可配置设置移除，默认开启；码内换行仍拒绝。码原文不做trim。
- 导出按序号每1000条分段读数据库，支持数万码，不一次载入全部数据库原文。
- 厂家/码管理员只能访问所属厂家；总部可跨厂家查看；只读账号可查看和下载，不能改生产资料。设备凭证仅能操作自己的采集，不能补填后台资料。
- 活跃外部批次纳入设备待处理统计和改线/再激活/删除保护；纯外码厂家也受到业务引用删除保护。新采集和删除厂家共用企业行锁。
