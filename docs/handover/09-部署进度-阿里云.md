## 3. 卡点：SSH 私钥被沙箱拒绝

**现象**：2026-09-15 16:20 左右执行访问 `.env` + 建库的命令时，沙箱弹出授权请求被**拒绝**，
错误为 `Load key "/c/Users/27475/.ssh/nz315_deploy": Permission denied`，
并列出被拦截路径：`C:\Users\27475\.ssh\` 整个目录。

**背景**：本会话先前多次 SSH 调用都被放行（结果里标 `Sandbox bypassed (escalation-approved)`），
只有这一条被拒。推测是当时弹出的授权提示被点了「拒绝」，或是授权超时自动拒绝。

**新对话里的处理方式**（按优先级）：
1. **首选**：直接在命令上请求提权 —— 给 Bash 工具加 `dangerouslyDisableSandbox: true`，
   用户在弹出的授权提示里点「允许」。一次授权即可继续跑完剩余步骤。
2. **备选**：AI 生成完整脚本，用户在**阿里云 Workbench 网页终端**或**宝塔终端**里粘贴执行，把输出贴回来。
3. **注意**：`run_in_background: true` 的 SSH 任务读私钥**必被拦**（本会话已实测），
   必须用**前台 SSH**，或让服务器端 `nohup ... &` 后台跑再轮询结果。
