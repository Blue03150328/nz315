## 2. 第三方接口（已接入）

### 2.1 微信公众号网页授权（消费者登录）— ✅ 凭据已配置

| 项 | 内容 |
|---|---|
| 用途 | 公众端「个人中心」识别消费者，扫码记录归属到人（`scan_log.consumer_id`） |
| 配置项 | `WECHAT_APP_ID`、`WECHAT_APP_SECRET`（`.env`，**已配置**，构建时内嵌） |
| 调用点 | `server/api/consumer/wechat/authorize.get.ts`（跳转授权）、`…/callback.get.ts`（换 openid + 拉用户信息） |
| 实际端点 | `https://open.weixin.qq.com/connect/oauth2/authorize`（`scope=snsapi_userinfo`）→ `https://api.weixin.qq.com/sns/oauth2/access_token` → `https://api.weixin.qq.com/sns/userinfo`（`lang=zh_CN`） |
| 数据落库 | `consumer` 表，`openid` 唯一；`unionid`/`nickname`/`avatar` 可空（拉取失败仅记 openid，个人中心显示「微信用户」） |
| 降级策略 | 未配置凭据 → 授权接口 **503**，**不做模拟登录**（项目红线） |
| 坑点 | ① **必须在微信公众平台配置「网页授权域名」**（公众号设置→功能设置）指向正式域名，**当前尚未配置**；② 运行期覆盖凭据要用 `NUXT_WECHAT_APP_ID` 前缀（否则构建时内嵌的旧值生效）；③ `state` 强制校验为**站内相对路径**（防开放重定向）；④ 需**已认证服务号**；⑤ 消费者 token 与后台 token 共用密钥但命名空间不同，**不可互换** |
| 待做 | 生产域名配置 + 真机验证回调；模板消息推送（未接入，需公众号对接） |

### 2.2 高德地图（两把 key，用途不可混用）— ✅ 已配置

| key | 配置项 | 用途 | 暴露面 |
|---|---|---|---|
| **JS API key** | `NUXT_PUBLIC_AMAP_JS_KEY` | 前端地图渲染（`https://webapi.amap.com/maps?v=2.0&key=…`，见 `app/composables/useAmapLoader.ts`） | **会暴露在浏览器**，上线前必须在高德控制台配置**域名白名单** |
| **Web 服务 key** | `AMAP_WEB_KEY` | 服务端 POI 周边检索（`https://restapi.amap.com/v3/place/around`，见 `server/api/stores/nearby.get.ts`） | 仅服务端，**绝不能下发浏览器** |

| 项 | 内容 |
|---|---|
| 业务用途 | 公众端「附近农资店」：定位 → 双关键词（`农药` + `农资`，后者需按名称过滤「农贸市场/市集」噪音）→ 距离升序取前 20 家，半径 30km |
| 缓存 | **1km 网格缓存 10 分钟**（防免费额度 QPS 超限） |
| 降级策略 | 未配 JS key → 页面自动降级为**纯列表**（定位与距离由浏览器定位 + 服务端计算，不依赖高德）；未定位 → 空引导开启定位 |
| 坑点 | ① **`setFitView` 只接受 `[lng,lat]` 数组**（传对象报 `getBounds is not a function`），同城多点须显式传 `maxZoom`；② 高德**地理编码/POI 会模糊匹配**，乱码地址照样返回高置信度结果→必须用业务侧已知省市交叉校验（本项目已弃用地理编码，仅用 POI）；③ 免费额度有 QPS 上限（`CUQPS_HAS_EXCEEDED_THE_LIMIT`），批量调用须限速；④ **浏览器定位是 WGS-84、高德是 GCJ-02**，必须经 `app/composables/useGeoConvert.ts` 的 `wgs84ToGcj02()` 转换（实测济南偏差 555 米）；⑤ 高德 2.0 若启用安全密钥方案，需补 `NUXT_PUBLIC_AMAP_SECURITY_CODE`（当前未配置） |

| 能力 | 现状 | 影响 / 建议 |
|---|---|---|
| **短信**（验证码/通知） | **完全未接入，无 SDK、无代码、无配置项** | 当前用户体系不使用手机验证码（密码登录 + 微信授权）。若上线运营需要短信通知/找回密码，需新选型（阿里云短信/腾讯云 SMS），并新增 `.env` 配置与发送工具模块 |

## 4. 依赖治理建议

1. **构建产物含明文凭据**：`.output/` 内嵌 runtimeConfig（含数据库密码）→ 部署目录权限收紧，禁止对外分发。
2. **锁文件必须入库**：`package-lock.json` 已跟踪（当前有未提交改动）；升级依赖后须重新构建 + 回归扫码主链路。
3. **`xlsx` 是唯一存在已知 CVE 的直接依赖**（0.18.5）：短期靠「仅管理员可上传」控制，长期应升级到 SheetJS 官方 0.20+ 或换成 `exceljs`。
4. **无 `engines` 字段**：`package.json` 未声明 Node 版本约束，建议补 `"engines": { "node": ">=20" }`。
5. **两把高德 key 的上线前动作**：JS key 配域名白名单、Web 服务 key 确认额度（POI 检索每请求 2 次调用）。
