# 码库剩余数量与生产使用记录

本机代码变更，未推送、未部署。账号登录模块由用户同事负责，本轮只提供使用记录查询与上传账号对接字段。

## 展示与计数

- 原码文件批次仍按 `upload_batch` 管理，每条码的 `trace_code.upload_batch_id` 保持原归属。生成并入库留档10万张，生产成功使用2万张后，总量显示10万张、累计已用2万张、剩余8万张，状态为“部分使用”。
- 使用量按真实已绑定码或生产任务已用码去重统计。任务创建、领用、待审核和转领不算使用；重复或拒绝的上传收据不扣减。历史已绑定码也计入累计已用，但不虚构对应生产任务和上传记录。
- 剩余包含仍被任务占用的未生产码，另列任务占用及当前可领数量。冻结、作废和资料不满足领用规则的剩余码不会被称为可领用。
- 数量计算及接口均使用精确整数。显示不足100张时保留精确数字；其余换算为万，最多两位小数，去除末尾零。82500张显示“8.25万张”，82501张显示“约8.25万张”；悬停可查看精确数量。
- 总量是当前批次内实际存在的码数量，沿用原码库统计；本轮未增加不可变生成总数字段。删除允许删除的未绑定码时，总量和剩余量相应变化。

## 使用记录接口

`GET /api/admin/codes/upload-batches/{id}/usage?page=1&pageSize=20`

使用现有后台登录认证，厂家仅可查询本企业，总部可查询各企业，只读账号可查看；非法参数400、匿名401、越权或不存在批次404。每页最多100条。

返回精确数量：`codeTotal`、`usedCount`、`remainingCount`、`taskUsedCount`、`legacyBoundCount`；并返回 `productionRecordsAvailable`、`unavailableReason`、`rows`、`total`、`page`、`pageSize`。

记录按生产任务、后台接收日期、上传来源和实际上传账号汇总，包含：

| 字段 | 含义 |
| --- | --- |
| `taskId/taskName/batchNo/lineName` | 生产任务、生产批号和生产线 |
| `count` | 本原码文件批次在该记录中的实际使用张数 |
| `usageDate/firstReceivedAt/lastReceivedAt` | 后台确认使用的日期与时间范围，北京时间，保留秒 |
| `firstCapturedAt/lastCapturedAt` | 移动端采集时间范围，北京时间；与后台收到时间分开 |
| `source/sourceLabel` | 有采集成功收据为 `mobile` / 移动端上传；旧直接扫码无明确客户端记录为 `online` / 在线扫码（客户端未记录） |
| `uploaderType/uploaderId/uploaderUsername/uploaderName` | 实际认证上传者；尚无个人账号时分别为 `unknown/null/null/null` |
| `deviceId/deviceName` | 设备信息，与个人上传账号分开 |

最早成功采集收据用于确定归属，重复、拒绝收据不进入记录。使用记录不能把任务创建人、原批次创建人或设备登记人当作上传者。

## 同事的账号模块对接约定

1. 本轮不添加个人登录页面、不改设备登录认证流程、不接收客户端自行填报的上传账号。
2. 现有个人账号上传入口为 `POST /api/admin/production-tasks/{taskId}/collection-sessions` 创建采集会话，以及 `POST /api/admin/production-tasks/{taskId}/collection-sessions/{sessionId}/events` 同步事件。这些入口使用后台登录会话；事件成功绑定时 `production_task_code.used_by` 记录本次认证用户ID。新采集会话另保存 `context_json.userUsername` 与已有 `userName` 快照。
3. 同事接入移动端个人认证时，在服务端验证账号，再把可信账号映射为上传流程中的 `AuthUser.id/username/name`。只有实际认证上传账号可以写入 `used_by`；请求正文中的任意账号ID不可信，不能直接落库。设备认证当前 `id=0` 的上传者字段保持空，前端显示“上传账号待接入”。
4. 原会话由管理员代为同步时，以本次 `used_by` 为实际上传者；只有与会话采集用户一致时使用会话中的账号快照。设备名称仍独立显示。个人身份与独立设备凭证如何同时验证、会话权限如何衔接，由账号模块实现并验收。

## 兼容与发布

本轮零DDL、零新增依赖；不迁移本机或生产业务库。原有生产任务、采集模块的表和必要列缺失时，码库仍可查看，已使用按现存绑定状态统计；使用记录、任务占用和可领量明确提示暂不可查询，未知数量不当成零。其他数据库查询错误正常报错，不伪装为空记录。

生产功能需先安装已合并版本原有的生产任务、采集和设备结构，本轮不新增迁移。上线需重打包含本轮改动的包；此前固定发布件不能代表本版本。

列表和打开的记录弹窗每20秒、恢复焦点及重新进入页面时刷新；切走页面停止轮询。弹窗取消旧请求，避免快速切换批次或页码时显示旧响应。
