### 🔧 两条已固化的流程铁律（33 号带下来的，本轮继续照做）

**① `mv .output .output.bak-<TS>` 必须在 `npm run build` 的紧前一行。**
24 号把它放在第 1 步 ⇒ 上一轮实测断静态资源窗口 **15:06 → 15:29 = 23 分钟**。原因：Nitro（node-server preset）的静态资源是**运行期从 `.output/public/` 读盘**的，不是打进进程内存 ⇒ `.output` 一改名，`/`、`/trace` 这类 **SSR 页面照旧 `200`**（服务端代码已在内存里），但 `/_nuxt/*.js`、`/_nuxt/*.css` **连接中断**、`/tools/*.exe` **`500`** ⇒ 用户看到「**页面有字、但没样式没交互**」。
⇒ **需要停顿判断的步骤（备份、迁移判据核对）全部放在 `mv` 之前，`mv` 之后一路跑到 build 结束。**

**② 判「包是否过期」只能逐文件比内容，绝不能比 SHA256。**
`git archive` 会在包首写 `pax_global_header`，**同内容、不同提交打出来的包 SHA256 必然不同** ⇒ 拿 SHA256 判新旧会得出「包全是新的」这种废结论。

### 1.2 备份数据库（整段粘贴）

> 🔴 **本轮【有 DDL】**，所以这一节的库备份**不是"按理说不太需要"，而是硬要求** —— 它是「建表出意外」时的唯一退路。

```bash
cd /var/www/nz315
while IFS='=' read -r k v; do v=${v%$'\r'}; case "$k" in DB_HOST|DB_PORT|DB_USER|DB_PASSWORD|DB_NAME) export "$k=$v";; esac; done < .env
echo "目标库: $DB_USER@$DB_HOST:$DB_PORT/$DB_NAME"
/www/server/mysql80/bin/mysqldump --no-defaults -h"$DB_HOST" -P"$DB_PORT" -u"$DB_USER" -p"$DB_PASSWORD" \
  --single-transaction --no-tablespaces --default-character-set=utf8mb4 "$DB_NAME" | gzip > $B/db-$DB_NAME.sql.gz
gzip -t $B/db-$DB_NAME.sql.gz && echo "备份包完整性 OK"
ls -lh $B/db-$DB_NAME.sql.gz
echo "---- 🔴 真正的判据：结尾必须有 Dump completed ----"
gzip -dc $B/db-$DB_NAME.sql.gz | tail -3
```

**期望**：打印 `目标库: nz315@127.0.0.1:3307/nz315` + `备份包完整性 OK` + 一个 **几 MB 到几十 MB** 的 `.sql.gz`，**且最后一段里能看到 `-- Dump completed on ...`**。

> 🔴 **两个判据缺一不可**：
> ① **文件大小合理**（不是几十字节）；
> ② **`gzip -dc … | tail -3` 里有 `-- Dump completed on …`**。
> **没有 `Dump completed` = dump 中途断了 = 没有回滚兜底，立刻重跑**（别信"没报错就是成功"）。
>
> 🔴 **`--no-tablespaces` 不能省**：MySQL 8.0 的 `mysqldump` 默认会去 dump 表空间元数据（`INFORMATION_SCHEMA.FILES`），**读它需要 PROCESS 权限**；本机库账号没有该权限时会打印
> `Access denied; you need (at least one of) the PROCESS privilege(s) ... when trying to dump tablespaces`
> —— **这个错是非致命的**（跳过表空间那一节、业务数据照 dump），但**光看有没有报错会误判成败**，所以判据必须落到上面那两条硬证据上。

**卡住了怎么办**

| 现象 | 处理 |
|---|---|
| `Access denied` | 把报错原样贴我（**别去试密码**） |
| `No such file or directory` | `ls -l /www/server/mysql80/bin/` 看实际有啥，贴我 |
| 包大小是 0 或只有几十字节 | dump 失败了，**别继续**（备份没成功就不该动生产） |
| 没有 `Dump completed` | **重跑本条**；连续两次都断，贴我看磁盘空间（`df -h /`） |
