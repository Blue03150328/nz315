## 2. P1 · 服务器部署（你在宝塔终端执行）

> **通用铁律**：`node` / `npm` 类命令必须带 `env PATH=/usr/local/node22/bin:/usr/bin:/bin`
> ⚠️ **`pm2` 相反：一律用裸命令 `pm2 ...`，不加任何 PATH 前缀**。PM2 CLI 的 Node 版本与 God Daemon 不一致时，PM2 会杀掉重建 daemon，而 daemon 与 cynx 共用 → **cynx 会挂**。pm2 必须走服务器默认 PATH（即当初 `pm2 start` 的环境）。
> ✅ **已实测**：`which pm2` = `/usr/local/bin/pm2`、`pm2 -v` = `7.0.3`；裸 `pm2` 与绝对路径是同一个二进制，**唯一禁忌是加 `env PATH=...` 前缀**。
> **只 `pm2 reload`**；`pm2 restart` / `pm2 kill` / `pm2 delete all` **一律禁止**（PM2 daemon 与 cynx 共用，会连累正式站）
> **绝对不许碰 cynx 的文件与进程**；nginx **只 `-s reload`**
