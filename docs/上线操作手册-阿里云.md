**关键路径是 ICP 备案，不是技术部署。** 技术侧一天能做完，备案少则一周多则四周，且**无法加急**。

**时间账**：合规硬节点 2026-11-01，今天 2026-09-12，**剩 50 天**。按最坏情况（备案 20 工作日 ≈ 4 周）算，10 月中旬能上线，留出 2 周验收缓冲。**但前提是备案今天提交**，晚一周就吃掉缓冲。

### 两条必须记住的硬约束

1. **未备案期间，域名不能解析到中国大陆服务器**。阿里云会拦截，访问必失败。所以备案期间**只能用 `http://<公网IP>:3000` 测试**，域名和 HTTPS 都上不了。

在服务器上以 root 执行仓库里的 `deploy/setup-server.sh`，它会装好 swap / Node 22 / MySQL 8 / nginx / PM2 并建好目录：

## 4. 备案通过后（顺序执行，半天可完成）

### 4.1 配 DNS 解析

阿里云控制台 → 云解析 DNS → `nz315.cn` → 添加记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---|---|---|---|
| A | `www` | ECS 公网 IP | 10 分钟 |
| A | `@` | ECS 公网 IP | 10 分钟 |

### 4.2 申请 HTTPS 证书

**方式一：Let's Encrypt（免费，90 天自动续期）**

```bash
dnf install -y certbot python3-certbot-nginx    # Debian 系用 apt

certbot certonly --webroot -w /var/www/certbot \
  -d www.nz315.cn -d nz315.cn \
  --email <你的邮箱> --agree-tos --no-eff-email
```

**方式二：阿里云免费证书**（控制台申请，下载 nginx 格式的 `.pem` + `.key`，上传服务器后把 nginx 配置里的证书路径换掉）

> ⚠️ 微信要求证书**链完整、未过期、与域名匹配**，否则用户点授权时会中断。

### 4.3 启用 nginx 站点配置

```bash
cp deploy/nginx-nz315.conf /etc/nginx/conf.d/nz315.conf
nginx -t && systemctl reload nginx
```

配置里的关键设计（`deploy/nginx-nz315.conf`）：
- 80 → 443 全量跳转，同时放行 `/.well-known/acme-challenge/` 供证书续期
- **`nz315.cn`（裸域名）301 到 `www.nz315.cn`** —— 微信回调域名取自请求头 Host，白名单只登记 www，用裸域名访问会撞微信 **10003**
- 反代 `127.0.0.1:3000` 并透传 `X-Forwarded-Proto`，会话安全 cookie 自动适配 HTTPS
- `client_max_body_size 60m`（码文件上传单文件上限 50MB）

### 4.4 配置微信「网页授权域名」⭐ 关键一步

此时 `https://www.nz315.cn/MP_verify_OUOoNSqTrpZkfWli.txt` 应已可公网访问，先浏览器验证一遍。

1. 微信公众平台 → 设置与开发 → 公众号设置 → 功能设置
2. **网页授权域名** 填 `www.nz315.cn`（**只填裸域名，不带协议/端口/路径**；该入口共限 2 个域名）
3. 保存时微信会**实时抓取**该文件校验 → 通过即保存成功
4. **若公众号开启了「IP 白名单」**，须把服务器**出口 IP** 加入，否则 callback 换 openid 时报 **40164**

> 常见报错对照：
> - `redirect_uri 参数错误` → 域名填错/带了协议，或代码侧 URL 未做 urlencode
> - `10003` → 用非白名单域名（IP、裸域名、带端口）发起授权
> - 保存时「域名未备案」→ 备案数据尚未同步到微信侧，等 1–2 天再试
> - 短时间内反复保存会触发**频率限制**，等 15 分钟

### 4.5 真机验证微信授权全链路

微信内打开授权入口 → 授权 → 带 code 跳回 → `consumer` 表落库 → `/profile` 展示。这是**唯一能证明链路通**的验证。

## 6. 故障速查

| 现象 | 处理 |
|---|---|
| 域名打不开、DNS 查不到 | 解析未配或未生效；`nslookup www.nz315.cn 223.5.5.5` |
| 域名访问被阿里云拦截页 | 备案未通过，大陆节点必然拦截；改用 IP 测试 |
| 502 Bad Gateway | Nitro 进程没起；`pm2 status` + `pm2 logs nz315 --lines 100` |
| 登录 500「生产环境必须配置独立 SESSION_SECRET」 | `.env` 的 `SESSION_SECRET` 仍是默认值；改强随机值后**重新构建** |
| 登录后立刻掉线 | `X-Forwarded-Proto` 未透传，cookie secure 判定失败；检查 nginx 配置 |
| 微信保存域名报「域名未备案」 | 备案数据未同步，等 1–2 天 |
| 微信报 10003 | 用了非白名单域名（IP / 裸域名 / 带端口） |
| callback 换 openid 报 40164 | 公众号 IP 白名单未加服务器出口 IP |
| 产品弹窗搜不到登记产品 | `pesticide_reg` 未导入，见 §3.7 |
| `nuxt build` 被 OOM kill | swap 没生效；`free -h` 确认，重跑 `setup-server.sh` |
| 上传大文件 413 | nginx `client_max_body_size` 未生效；`nginx -t` 后 reload |
