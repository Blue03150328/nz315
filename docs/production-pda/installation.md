# 设备登记与安装说明（2.2.0）

2026-10-10：后台设备登记功能和APK已上线，默认服务器为 https://www.nz315.cn。

APK下载：https://www.nz315.cn/downloads/nz315-production-2.2.0.apk

## 安装及首次登记

1. 在扫描仪下载并打开APK，选择覆盖更新。新旧包签名一致，不要卸载原应用，也不要清除应用数据。
2. 管理员登录网页，打开“生产任务与审核”，点击“设备管理 → 添加设备”。
3. 填设备名称，例如“扫描仪001”；选择公司和生产线。厂家管理员的公司自动确定，总部管理员可以选择公司。已有生产线提供输入建议，可填写新线名称。
4. 点击“登记并生成激活二维码”，二维码十分钟内有效，只供一台设备激活。
5. APK打开“扫码激活设备”，用扫描头扫描二维码。设备号和型号自动提交，不需要手动抄写。
6. 激活成功后显示公司、生产线和对应任务。选择本次任务，缓存领用清单，再点击“开始连续采集”。批号、日期、质检资料仍属于任务，设备只确定所属公司和生产线。

## 升级时还有旧采集任务

2.2.0会恢复旧队列，先使用原账号完成旧任务的同步和本机采集结束，然后关闭并重新打开APK，进入设备激活。不能将旧队列转换成新设备或其他公司的队列。安装时仅覆盖更新，不卸载。

若旧任务已结束但仍停在队列页面，先联网确认全部收据。所有设备会话关闭后才可结束生产任务并审核余码。

## 日常使用与设备管理

- 每台设备独立认证，打开APK自动识别归属，不再共用管理员账号登录。任务由管理员在后台建立；同产线有多个任务时选择本次任务。
- 开机必须联网完成首次领用清单缓存。已有缓存可离线采集；每次扫描先保存本机，再批量上传。关闭应用后重新打开自动恢复任务和待上传记录。
- 网址可以不同或不完整，只需能够提取唯一完整32位追溯码；保留前导零。同码去重，错误及未领用码保留异常原文，不计为有效生产。
- “本机已保存”与“云端已绑定”分别计数，设备得到云端收据后才确认同步。
- 管理员可编辑、停用、启用、删除、重新激活。删除从正常列表移除并撤销凭证，历史采集和管理记录保留。
- 设备有未结束采集会话时，禁止删除、重新激活和调换公司或生产线。先恢复启用，联网同步并结束本机采集；“上报待同步0”不能代替结束会话。
- 停用后服务器拒绝新的生产绑定；设备联网检测到后停止采集。设备离线时无法实时知道管理员停用，离线记录仍保留，不能当成已绑定。
- 跨公司改派后须重新激活。清除数据、卸载或恢复出厂可能丢失凭证和本机记录；有未上传记录时不能执行这些操作。
- “导出备份”保留本机采集、异常和收据，设备凭证不包含在备份中。设备损坏且存在未确认记录时，须核对备份与已生产清单，不能直接释放锁定余码。

## 已完成验收

- 后端设备登记12组隔离接口验收：权限与归属、一次性激活、幂等重试、多设备认证、产线隔离、会话隔离、去重、停用及并发提交、恢复、删除与重新登记、重激活、审计。
- 原生产采集9组回归：2000领用、1500生产、500审核转领，第二批使用500后第一批资料不变。
- Android/JVM队列、同步和HTTP客户端共27项单元测试通过；Android Debug与Online Lint及构建通过。
- UROVO i6310 Pro、Android12/API31实机：SQLite持久事务、Keystore加密及重新读取、激活响应重试、损坏凭证重新登记、二维码广播激活、公司产线加载、缓存领用清单。
- 实机断开测试连接后保存2个有效码、1个重复码、1个错误码；强制关闭应用后记录保留，恢复连接后4条收据分别为accepted、duplicate、accepted、rejected，最终完成设备会话和任务结束。
- 上线后HTTPS接口复核了激活、重试、公司产线、任务限制、停用/启用、删除与审计；只使用临时登记，未绑定任何线上生产码，临时记录已清理。

实机测试使用独立测试包和隔离数据库，模拟扫码广播与进程结束。正式生产线的连续实物扫描速度和实际电池耗尽场景仍需在现场试运行确认。

## 增量部署

本 PR 已包含完整增量源码。已有生产任务库先运行 `node scripts/migrate-production-collector.mjs`，再运行 `node scripts/migrate-production-devices.mjs`。先备份应用与数据库，并在候选目录安装锁定依赖、构建通过后执行迁移和切换。不要对真实业务库执行带演示数据的初始化。

增加两张采集会话/事件表、三张设备登记/激活/历史表，给采集会话增加可空 device_id 和索引；保留原追溯码、批次和账号数据。存在设备采集数据时不能直接回退到不支持设备身份的旧后端。

## 结束采集

“待同步记录 0”表示事件全部上传，不表示采集会话关闭。在扫码页面点击“结束本机采集及本批生产”，再在弹窗点“停止并同步”，等待自动返回任务列表。所有设备关闭会话后任务才可结束，剩余码进入管理员审核。
